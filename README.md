# Finanças da Casa

Aplicativo de organização financeira doméstica: orçamento com categorias e subcategorias, lançamentos, DRE mensal, patrimônio, metas, gráficos e análise automática.

- Funciona no navegador e pode ser instalado no iPhone (Safari → Compartilhar → Adicionar à Tela de Início) e no Windows (Chrome/Edge → Instalar app).
- Os dados ficam no Supabase, protegidos por login e regras de acesso. A chave em `config.js` é a chave pública (anon), feita para ficar no app.
- Funciona sem internet e envia as alterações quando a conexão volta.
